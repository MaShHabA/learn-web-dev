# Задание 3. Основы React

Страница выбора даты и времени для проекта «ХТОНЬ», перенесённая на React.

## Запуск

Нужен Node.js версии 20.19 или выше (для текущей версии Vite).

В терминале из этой папки выполните:

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:3000).

## Что работает

- при открытии страницы выбирается сегодняшний день и показываются его слоты;
- прошедшие дни нельзя выбрать;
- при выборе дня обновляются слоты, а выбранное время сбрасывается;
- свободный слот можно выбрать, занятые слоты недоступны;
- нижняя панель показывает выбранную дату и время;
- стрелки переключают месяцы, в том числе при переходе между годами.

## Что использовано из React

- компоненты и JSX;
- `useState` для хранения состояния;
- `.map()` для вывода дней и слотов;
- `key` для элементов списков;
- `onClick` для обработки кликов;
- props для передачи данных и функций между компонентами.

Чистые функции календаря перенесены в `src/data/date.js`.
